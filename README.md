# Paint Formula Pro

تطبيق Android أوفلاين للبحث في تركيبات ألوان الدهان.

## قاعدة البيانات
- 2,127 لون/كود فريد في بيانات المشروع.
- 187 أكواد RAL فريدة.
- 1,940 أكواد NCS فريدة.
- 12,754 تركيبة.
- لا يوجد استيراد CSV من الهاتف؛ قاعدة البيانات مدمجة داخل التطبيق.

## الحساب
الجرعات في قاعدة البيانات بالمليلتر (mL). حاسبة 5/10/18 كغ تعمل بالتناسب مع وزن مرجعي قابل للتعديل، والافتراضي 1 كغ. يجب مطابقة وزن المرجع مع معيار المصنع قبل اعتماد النتائج للإنتاج.

## البناء
يتم البناء عبر GitHub Actions باستخدام Capacitor. راجع `.github/workflows/build-apk.yml`.
